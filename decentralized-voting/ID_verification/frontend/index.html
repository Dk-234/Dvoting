📝 How It Works

  1. Enter your details — Fill in your ID type, ID number, name, and date of birth exactly as on your ID
  2. Upload your ID photo — Take a clear photo of your government-issued ID
  3. Cross-verification — The system extracts text from the ID image using OCR and compares it with the details you entered
  4. View results — See field-by-field match/mismatch comparison
  5. Blockchain registration — If verified, register a secure hash on the blockchain for voting eligibility
⚠️ Your actual ID number is NEVER stored. Only a secure hash is saved on the blockchain.
